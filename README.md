# Градостроительный симулятор

Репозиторий градостроительного симулятора, который мы разрабатываем.

Пока здесь только отдельные прототипы механик: каждая задача исследуется
изолированно, прежде чем войти в основной код игры.

## Структура

```
prototypes/
  crossroads/   — зонирование у перекрёстков дорог, пересекающихся не под прямым углом
  road-editor/  — редактор дорожной сети и участков на пустом поле
  life-sim/     — симуляция жизни: жители-агенты ходят между домом, работой и магазином
```

## Прототипы

| Прототип | Что исследует | Как запустить |
|---|---|---|
| [`prototypes/crossroads`](prototypes/crossroads/) | Зонирование у перекрёстка двух дорог под произвольным углом (20°–90°): ручное выделение участков по сетке улицы; автоматическое размещение дома у угла | Открыть `prototypes/crossroads/index.html` (участки) или `corner-house.html` (дом у угла) в браузере |
| [`prototypes/road-editor`](prototypes/road-editor/) | Свои дороги из узлов и звеньев (пересечения только в узлах), сетка зонирования по сторонам звеньев, участки по правилам `crossroads`, этажность и 3D-вид, типы домов (жилой, коммерческий, рабочий) и их вместимость, выезды во внешний мир, базовая деревня на 100 жителей, реальный район Белграда (Дорчол) из OpenStreetMap | Открыть `prototypes/road-editor/index.html` в браузере |
| [`prototypes/life-sim`](prototypes/life-sim/) | Симуляция жизни деревни без графики: места, жители с домом, работой и машиной, дороги со временем пути (этап 1 из 4) | `node prototypes/life-sim/run.mjs` |
