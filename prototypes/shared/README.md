# Общий код прототипов

[`city3d.js`](city3d.js) — 3D-вид города для всех прототипов: земля и клетки
зон, дороги, процедурные дома (фасады с окнами по клеткам и этажам, цоколь,
брандмауэры, карниз, мансардные и плоские крыши), выезды, жители-метки и
машины, управление камерой (двигать, вращать, наклон 60°/30°, масштаб).
Там же общая палитра карты (`City3D.COLORS`), стили домов (`City3D.STYLES`)
и цвет дома в 2D (`City3D.lotFill`), чтобы 2D тоже выглядело везде одинаково.

Кто использует:

- [редактор дорог](../road-editor/) — `<script src="../shared/city3d.js">`;
- [просмотрщик симуляции жизни](../life-sim/) — сборка
  `tools/build-viewer.mjs` вставляет файл в `viewer.html`.

Обычный скрипт без модулей (глобальный `City3D`), нужен three.js r128 —
`City3D.loadThree()` подгружает его с cdnjs. Единицы — как в редакторе:
клетка = 16 единиц (4 м), этаж = клетка. Описание сцены — в начале файла.
